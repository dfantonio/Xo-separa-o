## Codebase Patterns
- All app code lives under `/workspace/xo-separacao/` (not the workspace root)
- Navigation stack types defined in `src/navigation/types.ts` as `RootStackParamList`
- Session persistence uses `expo-secure-store` with key `sessionId`
- Firebase config in `src/config/firebase.ts` exports `db` (Firestore instance)
- Typecheck runs with `npx tsc --noEmit` from `/workspace/xo-separacao/`
- Git commits are made from `/workspace` (repo root)
